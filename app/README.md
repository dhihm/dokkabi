# Dokkabi App

macOS Electron/React desktop shell derived from T3 Code by T3 Tools Inc. and
contributors. [UPSTREAM.md](UPSTREAM.md) retains provenance; [LICENSE](LICENSE)
retains its MIT text. This is independently maintained and does not imply
T3 Tools endorsement.

The main conversation and composer remain available alongside Work/Context
graphs, node evidence, retained Record and its companion, usage and explicit
decision/branch checkpoints. Dokkabi's harness owns execution and completion
authority. Inherited provider adapters are not equivalent to Dokkabi execution.
Automatic deadline branching and large-workload performance remain partial.

See [../BUILD.md](../BUILD.md) for committed-lock builds and unsigned manual
installation. GUI support is macOS only; arm64 has bounded installed evidence.
Automatic updates are disabled. Inherited mobile, cloud and non-macOS desktop
code remains for source/build closure and is outside the product release promise.
No upstream deployment or release workflows are included.

Dokkabi and runtime notices are in [licenses/](licenses/) and Settings → Open
source licenses after regenerating the manifest. Bun has separate linked-library
terms; MIT attribution alone does not clear bundled runtime redistribution.
