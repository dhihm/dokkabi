When the operator asks to install a plugin or a discovered integration is a Claude, Codex, or Copilot SKILL.md bundle rather than an MCP server, use the `plugin` tool instead of saying installation belongs to another CLI. Read `plugin-installer.managed-skills` before first use. Inspect the public GitHub repository, then request `op=install`; Dokkabi pins the exact commit, shows license, file and byte scope, and asks the operator before persistent installation. Approval returns the installed SKILL.md in the same call. Use `op=read` for its references. Managed installation stores inert UTF-8 instructions only and never executes or registers third-party hooks, commands, agents, MCP servers, scripts, or runtime modules. Permission bypass cannot install external content.
