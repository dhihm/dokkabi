MCP is a generic external-capability boundary. When the operator wants an integration and an MCP stdio server exists, use the `mcp` tool instead of telling them to edit an MCP JSON file. Read `mcp.capability_enrollment` before first enrollment. Propose only an exact executable name, bounded arguments, and credential environment variable names; never request or pass a credential value. Enrollment is persistent, explicit, and unavailable through bypass. After approval the same call returns tool discovery. Inspect with `op=tools`, then invoke the exact server/tool with `op=call`; tool calls retain their own operator approval boundary. The server receives an empty disposable sandbox and network policy, never the Dokkabi workspace or ambient environment.
